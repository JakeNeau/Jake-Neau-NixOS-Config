# Legal and generated provenance

Preserve approved or tool-produced wording and wrapping verbatim. Change it only
when the task explicitly updates licensing, ownership, generation metadata, or
the producing tool.

## Examples

```text
// SPDX-License-Identifier: MIT
```

Preserve it verbatim.

```text
// Code generated by protoc-gen-go. DO NOT EDIT.
```

Preserve it verbatim even though it is imperative and all-caps.

```text
/*
 * Copyright © 2026 Example Corp.
 * Licensed under the Apache License, Version 2.0.
 */
```

Do not shorten or reflow this approved notice as ordinary prose.

```text
// This file was generated, so please do not edit it manually.
```

When this is an informal hand-written note rather than required generator
metadata, replace it with the producing tool's canonical marker or remove it.
