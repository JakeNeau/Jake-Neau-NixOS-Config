# Refine an implementation plan

Read the workflow input, project instructions, relevant documentation, and the target specification. Inspect only the code needed to make the plan actionable. Reuse the project's documented plan location and naming convention.

If the input is empty, inspect active plans and select one clear, high-impact gap. Do not audit every implementation detail.

Prepare one concise implementation plan. Name the required files, symbols, behavior, data flow, errors, tests, and documentation changes. Keep decisions at implementation level. Do not include routine commands or redundant verification steps.

Return one `refinement-proposal` artifact with `workflow_output`. Put the complete plan text in `payload.design`. List exactly one plan file in `payload.files`. Do not modify files.
