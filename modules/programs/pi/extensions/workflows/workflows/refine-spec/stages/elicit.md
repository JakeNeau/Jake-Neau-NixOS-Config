# Elicit the next design decision

Review the evidence synthesis and all recorded user decisions. If a material
decision remains, ask exactly one question. Choose the decision with the
largest effect on later choices.

Provide two to five distinct options. Give each option a short label and a
concrete consequence. Include a recommendation only when evidence supports it.
Do not ask for facts that the project already establishes.

If no material decision remains, return `ready` and explain why the design can
be proposed. Otherwise return `question`. Finish with `workflow_output`.
