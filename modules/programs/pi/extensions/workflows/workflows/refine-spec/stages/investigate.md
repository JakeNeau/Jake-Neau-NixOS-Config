# Investigate one refinement lens

Investigate only the supplied focus item and lens. The lens is one of
`specification`, `documentation`, `implementation`, or `verification`.

Follow project documentation before reading broad code. Gather evidence that
changes a design decision. Record each claim beside its source excerpt and
explain what the evidence means. Separate verified facts from assumptions.

List constraints and unresolved questions. Do not propose a complete design,
ask the user, or modify files.

Return one `evidence` artifact with `workflow_output`.
