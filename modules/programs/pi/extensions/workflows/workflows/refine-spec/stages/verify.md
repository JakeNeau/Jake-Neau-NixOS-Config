# Verify the written refinement

Read the changed specifications and compare them with the accepted proposal,
every recorded user decision, project architecture, and relevant implementation
evidence. Run documented read-only specification checks when available.

Fail verification for an omitted decision, contradiction, unsupported claim,
out-of-scope change, invalid project check, or unclear acceptance criterion.
Give each finding a concrete correction.

Return `passed` only when the refinement is complete and consistent. Otherwise
return `failed`. Finish with `workflow_output`.
